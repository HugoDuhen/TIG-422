# Maquette graphique — non implémentée

Proposition de style visuel plus travaillé pour le site (bandeau bleu marine/doré,
icônes par poste, distinction section/compagnie par couleur). Validée par Hugo
pour le fond, mise de côté pour un déploiement ultérieur.

- `*.jpg` — rendus des 5 vues (Jour en desktop et mobile, Semaine, Mois, Chambre, Récap)
- `source/*.html` — pages HTML autonomes utilisées pour générer ces images (CSS inline,
  données d'exemple figées au 5 octobre 2026)

Ce dossier est purement un stockage de référence : il n'est pas importé par l'app
Next.js (`app/`, `lib/`, `data/`) et n'a aucun effet sur le site en production.
